# 训练脚本改动说明（原版 → TinyML 合规版）

> 结论：队友的 `examples/Iris:fast_neural_style` **不能直接用**。
> 需要改 **3 类算子**（架构级）和 **2 个环境兼容 bug**（跑都跑不起来）。
> 本目录的 `flatfns_model.py` / `train.py` / `utils.py` 是改好的版本。

---

## 一、为什么不能直接用：实测证据

用队友自己的脚本 `script/model2tf_lite.py` 把 `one_last_kiss_style.model`
转成 tflite，算子清单是（`deploy/out/smoke-test-报告.md` 有完整记录）：

| 算子 | 个数 | TinyML 白名单 | 来源 |
|---|---:|---|---|
| `CONV_2D` | 16 | ✅ | 卷积 |
| `ADD` | 35 | ✅ | 残差 |
| `MUL` | 45 | ✅ | InstanceNorm 分解 |
| **`MIRROR_PAD`** | **16** | ❌ | `ReflectionPad2d` |
| **`MEAN`** | **30** | ❌ | `InstanceNorm2d` |
| **`SUB`** | **15** | ❌ | `InstanceNorm2d` |
| **`SQRT`** | **15** | ❌ | `InstanceNorm2d` |
| **`DIV`** | **15** | ❌ | `InstanceNorm2d` |
| **`RESIZE_NEAREST_NEIGHBOR`** | **2** | ❌ | `nearest×2` 上采样 |

**7 类、93 个算子**会掉回 RISC-V 软件执行 —— 不会报错，但性能差 1~2 个数量级，
而且 15 个 InstanceNorm 全在关键路径上。

## 二、算子改造（架构级，必须重训）

| # | 原结构 | 改成 | 消除的算子 | 为什么可行 |
|---|---|---|---|---|
| 1 | `ReflectionPad2d(1)/(4)` + Conv | `Conv2d(padding=k//2)` **零填充** | `MIRROR_PAD ×16` | 零填充会被 `CONV_2D` 的 `SAME` padding 直接吸收，图里**不产生算子**；反射填充必须由独立算子实现 |
| 2 | `InstanceNorm2d(affine=True, track_running_stats=False)` | `BatchNorm2d`，**导出前折叠进卷积** | `MEAN/SUB/SQRT/DIV ×75` | BN 是逐通道仿射变换 → 可离线折叠成 `W'=W·γ/√(σ²+ε)`、`b'=β-μγ/√(σ²+ε)`，折叠后**零算子**；IN 是逐图逐通道统计，无法离线折叠 |
| 3 | `deconv1/deconv2`（`nearest×2` + pad + conv） | **删掉**，整网改单分辨率全卷积 | `RESIZE_NEAREST_NEIGHBOR ×2` | TinyML 没有 resize 加速配置；放大改由显示侧硬件做（`hw_accel_nearest_neighbor_downscale` 同族模块） |
| 4 | 独立 `nn.ReLU` 层 | ReLU **紧跟** Conv+BN | 独立 `RELU` | TFLite 会把紧跟卷积的 ReLU 融合进 `CONV_2D` 的 `activation`，不产生独立算子 |

**保留**：`CONV_2D`（卷积）、`ADD`（残差）—— 两者都在白名单。
`add_drv()` 的签名带 `input1/2_multiplier + shift + offset`，说明**残差两端量化参数不同也能加速**，所以残差连接可以放心保留。

## 三、环境兼容 bug（不改根本跑不起来）

这两个不是算子问题，是队友代码在现代依赖上直接崩掉：

### bug 1：`PIL.Image.ANTIALIAS` 已被移除（Pillow ≥ 10）

`neural_style/utils.py:10,12`：
```python
img.resize((size, size), Image.ANTIALIAS)
```
```
AttributeError: module 'PIL.Image' has no attribute 'ANTIALIAS'
```
**修法**（已改）：
```python
_RESAMPLE = getattr(getattr(Image, "Resampling", Image), "LANCZOS", None) \
    or getattr(Image, "ANTIALIAS", None)
```

### bug 2：`normalize_batch` 原地修改导致 autograd 报错

`utils.py:35` 用 `batch.div_(255.0)` 做**原地**除法，而训练循环里
`x = utils.normalize_batch(x)` 发生在 `y = transformer(x)` **之后**，
原地改掉了 autograd 为卷积反向传播保存的输入张量：

```
RuntimeError: one of the variables needed for gradient computation has been
modified by an inplace operation: [torch.FloatTensor [2, 3, 64, 64]] is at version 1;
expected version 0 instead.
```
**修法**（已改）：`batch = batch / 255.0`（非原地，语义等价，且不再污染调用方张量）。

## 五、怎么用

```bash
source /mnt/mydata/Iris/deploy/.venv/bin/activate
cd /mnt/mydata/Iris/deploy

# 1) 训练（云主机上把 --accel 打开；--dataset 要指向"内含一层子文件夹"的目录）
python train/train.py train \
    --dataset /root/gpufree-data/coco \
    --style-image /mnt/mydata/Iris/examples/fast_neural_style/images/style-images/one_last_kiss.png \
    --save-model-dir out/runs/ol_kiss \
    --epochs 2 --channels 16 --blocks 3 --accel

# 2) 导出 ONNX（自动折叠 BN + 跑 G1 门禁）
python train/export_onnx.py --weights out/runs/ol_kiss/epoch_2_*.model \
    --out out/flatfns.onnx --channels 16 --blocks 3 --size 128

# 3) 全整数 INT8 量化
python quant/to_tflite.py --onnx out/flatfns.onnx \
    --calib /mnt/mydata/Iris/examples/fast_neural_style/images/calib \
    --out out/flatfns_int8.tflite --keep-float-tflite

# 4) 算子合规门禁（G2/G3，可直接当 CI）
python verify/ops_inventory.py --model out/flatfns_int8.tflite --report out/compliance.md

# 5) 量化精度（G4）
python verify/check_equiv.py --int8 out/flatfns_int8.tflite \
    --float out/flatfns_int8_float32.tflite --content <某张图>.jpg
```

## 六、选档位（按 Ti60 资源）

`python train/flatfns_model.py` 会打印档位表。关键点：
**参数量 ≡ 每像素 MAC 数**（3×3 卷积权重不复用），所以 L5c 的 500 KB 约束根本不是瓶颈，
**算力才是**。所有档位 INT8 权重都 <100 KB。

| C | N | MAC/px | INT8 | 128×128 MMAC/帧 | @15fps |
|---|---|---|---|---|---|
| 16 | 3 | 14,688 | 14.3 KB | 241 | 3.6 GMAC/s |
| 16 | 4 | 19,296 | 18.8 KB | 316 | 4.7 |
| 24 | 3 | 32,400 | 31.6 KB | 531 | 8.0 |
| 32 | 3 | 57,024 | 55.7 KB | 934 | 14.0 |

> 加速器实测 GMAC/s 要用 Efinity TinyML Generator 的 Resource Estimator
> + 板端 profiler 才能定（计划里的 G5），目前缺 Efinity 装不上。
