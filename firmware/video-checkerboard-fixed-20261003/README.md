# 固定棋盘色彩参数与 KEY2 图像冻结固件

Q8 RGB 增益 470/305/731，显示黑位 21/23/20，来自参考照明下 12×9 棋盘的五幅有效 RGB 图像。固定参数不随启动场景、KEY2 或曝光补偿改变。

已通过 RTL/主机拟合测试、全部 Efinity 构建与时序检查（setup +0.011 ns、hold +0.026 ns）。已写入 W25Q64 Flash 地址 0，并回读校验成功；已从 Flash 启动，用户 KEY2 采集后串口两次读图 CRC 通过、图像完全一致；运行复验保持原生 1920×1080 / 60.044 fps，CAM/WR 为 60。

KEY2 采集并冻结下一完整帧的 96×54 线性 RGB 缩略图，LED2 亮表示完成。UART C 只读取所保存图像，不重新拍摄。KEY3 无校准功能。快照掉电丢失，色彩参数保存在此 Flash 固件中。

采样/拟合、源码 SHA 清单、测试、构建及 Flash 证据：docs/validation/20261003-checkerboard/。
