# 1080p60 / 4K30 YCbCr420 双模式固件

默认启动 1080p60 RGB。KEY3 在显示读帧 VS 边界切换到放大的 3840×2160p30 YCbCr420 8-bit，再按一次返回。KEY2 保存棋盘采样图，KEY0/1 保留曝光补偿。

摄像头始终原生 1920×1080，约 60.044 fps；4K 不是原生采集。两种输出均使用同一 148.75 MHz TMDS 字时钟（1.4875 Gbit/s/通道），标称输出约 60.10 / 30.05 Hz。4K 模式要求显示器支持该格式。

烧录使用 `.script/sync-iris` 的 Flash 模式。本目录含设计位流及 SPI 镜像，源文件散列和验证记录见 docs/validation/20261003-dual-output。
