# CNN 彩色笔触与轮廓调参

2026-10-17：原始 CNN 已有彩色条纹，本次修复显示后处理对这些色纹的削弱。
此前相机占 75% 的混色方案已撤回；当前右侧全部使用 CNN 的 RGB 颜色。

## 色纹为什么会变淡

旧 `render()` 使用 `base=255-((255-minimum+2)>>2)` 把最暗通道抬向白色，
其他通道随之裁剪到 255，减小了 CNN 原有的 RGB 差异。
轮廓或对比度压暗若超过最暗通道，还会逐通道裁剪到黑色，吞掉暗处彩色笔触。
上一轮新增的相机混色只保留 25% CNN、每通道 32 级色阶，也会淡化和量化细纹，
因此本轮一并取消。

这些是显示问题。修复保留当前 CNN 权重、输出张量及反量化比例，
不使用相机原色替换 AI 的风格颜色。

## 当前显示处理

`h`/模式 2 和 `s`/模式 3 先从原始 CNN RGB 提取最大通道 M，
保持最亮通道不变，按参数放大其他通道与 M 的差距。
默认 `SATURATION_Q2=8`，对应 2 倍色差：

```
C' = max(0, M - ((M-C) * SATURATION_Q2 + 2) / 4)
```

公式中的除法取整，与 RTL 的右移一致。比如 CNN RGB 为 `(250,245,247)`，
增强后是 `(250,240,244)`；不会把三个通道一起抬成白色。
没有颜色级数压缩，浅色的逐像素细纹能够保留。中性灰仍保持中性灰。

轮廓仍由相机亮度的 5×5 平滑梯度产生。对 RGB 使用共同压暗量，
并限制它不超过增强后最暗通道：

```
dark = min(ink, min(R',G',B'))
RGB_out = RGB' - dark
```

因此轮廓叠加前后的通道差保持一致，彩色笔触不会因分别裁剪到黑色而消失。
模式 `c` 也采用相同的压暗保护；`n` 完全透传原始 CNN 反量化颜色。
高饱和彩色笔触处会限制黑线深度，这是保留 AI 颜色所需的处理。

相机只提供轮廓的亮度邻域，不提供右侧 RGB。
上一轮新增的原图 RGB 端口、混色流水线及相机颜色缓存已去除，
恢复原有四行紧凑 RGB 与六行灰度缓存，面板延迟仍为 7 个双像素时钟。

## 调参顺序

直接修改 `iris_ws/src/cnn/iris_style_contour.v` 开头的参数，每次只改一项。

| 参数 | 当前值 | 建议调法 |
|---|---:|---|
| `SATURATION_Q2` | 8 | 放大 CNN 色差。4=原色差，6=1.5 倍，8=2 倍，12=3 倍；范围 4..16。先比较 4、8、12。 |
| `NORMAL_THRESHOLD` | 20 | `h` 的轮廓门槛，保留用户修改。杂线多依次试 32、48、64；线条太少再降低。 |
| `NORMAL_INK_GAIN` | 2 | 门槛以上的线条加深速度。默认 2；希望更重可试 4。 |
| `NORMAL_INK_CAP` | 128 | 轮廓请求的压暗上限。过黑试 96；更重试 160。实际压暗仍受最暗通道保护。 |
| `STRONG_THRESHOLD/INK_GAIN/INK_CAP` | 40 / 4 / 160 | 只影响 `s`，用于更重的主轮廓。 |

先用 `n` 对照原始 CNN 色纹，再切 `h` 观察增强；先调整颜色，最后调整轮廓。
两档共用 `SATURATION_Q2`；`NORMAL_*` 仅作用于 `h`，`STRONG_*` 仅作用于 `s`。
原来的 `SOURCE_MIX_Q2`、`COLOUR_BITS` 已移除，以免再次稀释 CNN 或抹掉细纹。

`SCALE_Q24` 是模型的反量化比例，当前值 20596120，
由 `iris_ws/iris_ws.xml` 的 `STYLE_SCALE_Q24` 经顶层传入。
保持它与模型一致；仅改子模块默认值也会被上层工程配置覆盖。

| UART 单字符 | 显示 |
|---|---|
| `n` | 原始 CNN RGB，用于对照 |
| `c` | CNN 对比度增强，限制压暗以保留色差 |
| `h` | CNN 彩色笔触增强 + 平滑主轮廓，默认 |
| `s` | 同样保留 CNN 颜色，加重主轮廓 |

UART 模式请求仍在 VS 生效。Verilog 参数为编译期参数，修改后需重新构建并加载位流。

## 离线预览

以下命令读取已有硬件快照，不操作板卡。默认参数自动读取当前 RTL。

```sh
python3 .script/render-style-visibility.py docs/validation/20261008-tinyml/stream-d2-camera --contour --mode 2 --compare --output /tmp/iris-cnn-colour.png

# 只改变预览：3 倍 CNN 色差，轮廓门槛提高到 32。
python3 .script/render-style-visibility.py docs/validation/20261008-tinyml/stream-d2-camera --contour --mode 2 --saturation-q2 12 --threshold 32 --ink-gain 2 --ink-cap 128 --compare --output /tmp/iris-cnn-colour-strong.png
```

四栏依次是采集原图、原始 CNN、旧漂白轮廓、新版 CNN 彩色轮廓。
示例在 `docs/validation/20261017-neural-colour/`。
这是离线显示参考，实屏效果需加载新位流后确认。
